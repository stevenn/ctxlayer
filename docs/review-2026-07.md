## 3. Test coverage

- **`packages/shared` has zero tests across ~3000 LoC** — `"test": "echo 'no
  tests for shared yet'"`. Highest value, all pure functions:
  `url-trust.ts` (**a security boundary**), `frontmatter.ts` (an OKF round-trip
  *preservation* contract with nothing asserting it — unknown keys, comments,
  ordering, block scalars), `tool-name.ts`, `okf-links.ts`, `entitlement.ts`,
  `slug.ts`.
- **`test:e2e` is a stub that exits 0**, so `bun run test:e2e` reports success
  having run nothing. Either implement it or make the stub's status honest.
- `biome.json` — `useExhaustiveDependencies: "off"` repo-wide across 50+ hooks.
  ~6 sites deliberately under-declare deps (with comments); `"warn"` + those
  ignores would cover the other ~44.
